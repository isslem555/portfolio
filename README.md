# Portfolio — Isslem Mejri

Portfolio professionnel moderne, animé et responsive.

## Structure des fichiers

```
portfolio/
├── index.html          ← Structure complète du portfolio
├── style.css           ← Design, animations, thème dark/light, responsive
├── script.js           ← Aurora, curseur, typing, reveal, compteurs, filtre
└── assets/
    └── Isslem_Mejri_CV.pdf   ← ⚠️ À placer ici pour le bouton de téléchargement
```

## Comment lancer

**Option simple :**
1. Ouvrir le dossier
2. Double-cliquer sur `index.html`

**Option recommandée (VS Code) :**
1. Ouvrir le dossier dans VS Code
2. Installer l'extension **Live Server**
3. Clic droit sur `index.html` → **Open with Live Server**

## À personnaliser

Dans `index.html` :
- Remplacer `href="#"` du lien GitHub par votre vrai lien
- Ajouter les liens de démo ou GitHub de chaque projet

Dans `assets/` :
- Placer votre fichier CV au bon nom : `Isslem_Mejri_CV.pdf`

## Fonctionnalités

- ✨ **Aurora canvas** — fond animé avec blobs lumineux
- 🖱️ **Curseur personnalisé** — avec effet magnétique et trail
- ⏳ **Loader élégant** avec barre de progression
- 🌙 **Thème dark/light** — persisté en localStorage
- ⌨️ **Typing effect** — animation de texte animé
- 📜 **Scroll reveal** — apparition progressive des sections
- 📊 **Barres de compétences animées** — déclenchées au scroll
- 🔢 **Compteurs animés** — statistiques hero

- 🃏 **Tilt effect** — sur les cartes (effet 3D)
- 🌐 **Parallax** — orbe hero suivant la souris
- 📈 **Barre de progression** — de lecture en haut de page
